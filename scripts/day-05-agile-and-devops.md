# Day 5 — Agile and DevOps

100 Days of DevOps · Reel · ~79 seconds (voiceover: Prasad – Calm, Proud, Deep)

Day 4 lo Traditional IT ki DevOps ki madhya difference telusukunnam kada!

Mari ippudu oka important question… **Agile ante enti? DevOps tho daniki connection enti?**

Agile ante software development ni small-small steps lo divide chesi, frequent ga feedback teesukuntu improve chese approach!

Example ki, oka team oka big application ni okesari develop cheyakunda, small features ga divide chestundi.

Prathi feature ni develop chesi, test chesi, user feedback batti improvements chestundi.

Ippudu DevOps ekkada use avuthundi?

Agile development process ni fast and flexible ga cheyadaniki help chesthe, DevOps aa software ni build, test, deploy, and monitor cheyadaniki help chestundi.

Example ki, Agile team oka new feature develop chesindi anukondi. DevOps tools and CI/CD pipeline use chesi, aa feature ni automatic ga test chesi, deploy cheyadaniki help chestayi.

**Simple ga cheppalante… Agile helps teams build the right software, and DevOps helps teams deliver and operate that software reliably.**

Rendu kalisi work chesthe, software ni faster ga release cheyachu, feedback quick ga teesukovachu, and continuous ga improve cheyachu!
