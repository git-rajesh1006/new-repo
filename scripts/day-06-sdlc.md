# Day 6 — SDLC (Software Development Life Cycle)

100 Days of DevOps · Reel · ~64 seconds (voiceover: Prasad – Calm, Proud, Deep)

Oka software ni fast ga develop cheyali ante… coding okkate saripodu! 🔥

Software idea nunchi users daggariki reach ayye varaku oka proper process untundi. Ade **SDLC — Software Development Life Cycle!**

Day 5 lo Agile and DevOps gurinchi telusukunnam kada! Ippudu SDLC ela work avuthundo chuddam.

SDLC lo first, **Planning** — application lo em features undalo decide chestham.

Next, **Design and Development** — application design chesi, code rastam.

Tarvata, **Testing** — application lo bugs unnayo ledo check chestham.

Next, **Deployment** — application ni server lo release chesi users ki available chestham.

Finally, **Maintenance** — application ni monitor chesthu, problems fix chesi improve chestham.

Simple ga cheppalante, SDLC anedi software ni plan cheyadam nunchi maintain cheyadam varaku follow ayye complete process!
